## Comment c'est fait

Pas de framework : du HTML, du CSS et du JavaScript écrits à la main. Le site est hébergé gratuitement avec GitHub Pages, sur mon propre nom de domaine.

```
├── index.html            la page principale
├── projets/              les études de cas
├── css/                  le style
├── js/                   les scripts (traduction, thème, animations)
├── images/               les photos et icônes
├── cv/                   mes CV en PDF et leurs sources LaTeX
├── 404.html              la page d'erreur
├── robots.txt, sitemap.xml
└── CNAME                 le nom de domaine
```

Pour le voir en local, il suffit d'ouvrir `index.html` dans un navigateur, ou de lancer `python -m http.server` dans le dossier puis d'aller sur `http://localhost:8000`.
